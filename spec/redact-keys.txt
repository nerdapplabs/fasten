# fasten canonical redact-key patterns
#
# Single source of truth for all language adapters.
# Each line is one case-insensitive regex alternation.
# The combined pattern is: ^(line1|line2|...)$ matched against field *keys*.
# Values are replaced with the replacement token (default "***").
# Keys are preserved — presence of a secret field is observable, value is not.
#
# Rules:
#   - patterns are case-insensitive in all adapters
#   - [_-]? means the separator is optional (api_key, api-key, apikey all match)
#   - adopters may ADD keys via init(extra_redact_keys=[...]) but never remove defaults
#
# To add a key: append a line here, then update each language adapter.
# CI gate: scripts/check-redact-parity.sh verifies all adapters match this file.
